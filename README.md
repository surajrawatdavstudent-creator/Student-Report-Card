# Student Report Card

This is a simple Python project that creates a basic student report card.

## What this program does

The program asks for:

* Student's name
* Marks of 5 subjects

Then it shows:

* Highest marks
* Lowest marks
* Total marks
* Percentage
* Grade

## Grade System

| Percentage  | Grade |
| ----------- | ----- |
| 90 or above | A     |
| 75 to 89    | B     |
| Below 75    | Fail  |

## How to Run

First, make sure Python is installed.

Run the file using:

```bash
python report_card.py
```

Then enter the student's name and marks when asked.

## Example

```text
# Hey this is a report card of a brilliant student
Enter name of a student : Suraj
Enter marks of your subject 1 : 95
Enter marks of your subject 2 : 87
Enter marks of your subject 3 : 92
Enter marks of your subject 4 : 89
Enter marks of your subject 5 : 96

You got highest marks in : 96
You got lowest marks in : 87
Your total marks are : 459
Your percent is : 91.8
You got Grade A
```
