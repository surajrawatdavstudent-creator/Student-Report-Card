# Student Report Card

A small Python project that creates a basic student report card.

## What the program does

The program asks for a student's name and marks in five subjects. It then shows:

- Highest marks
- Lowest marks
- Total marks
- Percentage
- Grade

## Grade System

| Percentage | Grade |
|---|---|
| 90 or above | A |
| 75 to 89 | B |
| Below 75 | Fail |

## Python Concepts Used

- `input()`
- Variables
- `int()`
- `print()`
- `max()` and `min()`
- Arithmetic operations
- `if`, `elif`, `else`
- Comparison operators

## How to Run

Make sure Python is installed, then run:

```bash
python report_card.py
```

Enter the student's name and marks when asked.

## Example

```text
Enter name of a student : Suraj
Enter marks of your subject 1 : 95
Enter marks of your subject 2 : 87
Enter marks of your subject 3 : 92
Enter marks of your subject 4 : 89
Enter marks of your subject 5 : 96
```

The program then calculates the total, percentage, highest mark, lowest mark, and grade.
